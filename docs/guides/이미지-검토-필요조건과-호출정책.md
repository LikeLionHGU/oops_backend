# 이미지 검토 필요조건과 호출 정책 — 2026-10-23

## 원칙

**현재 판단에 필수이며 선택 이미지에서 관측할 수 있는 사실이 있을 때만 호출한다.** 더 많은 정보가 있으면 좋겠다는 이유만으로 모든 후보에 이미지를 붙이지 않는다. OCR, 선택 이미지 검토, 원음 검토는 서로 다른 입력과 목적이다.

| 현재 부족한 정보 | 적절한 경로 | 이미지 호출 여부 |
| --- | --- | --- |
| ‘이것/여기’가 가리키는 사물·공간과 발언의 연결 | 해당 후보 주변 선택 프레임 | 구체적 연결이 판단에 필수일 때 |
| 화면 문구가 편집 자막인지, 인용 자료·메뉴판·배경인지 | 제공 텍스트의 출처·배치 확인 | 그 역할이 판단을 바꾸고 대상 프레임이 있을 때 |
| 발언과 화면에 제시된 물건·표시의 비교 | 특정 화면 사실 확인 | 사실을 구체적으로 질문할 수 있을 때 |
| 이미지에 정보가 실제 보이는지 | 선택 구간 화면 확인 | 특정 의심 구간이 있을 때. 전체 영상의 노출 검사를 대신하지 않음 |
| 비꼬는 억양·웃음소리·말투 | 원음/연속 클립 검토 | 정지 이미지로 해결하려고 호출하지 않음 |
| 표정으로 추정한 악의·불쾌감·동의 | 현재 자료로 확정 불가 | 추측 보강용으로 호출하지 않음 |
| 사건의 실제 발생·외부 시기·의도 | 확인된 외부 맥락 또는 추가 자료 | 이미지가 사실 대조를 대신하지 않음 |
| 텍스트만으로 충분한 위협·신체 비유·인용 관계 | 기존 텍스트 경로 | 기본 불필요 |
| 텍스트 후보 없이 화면에만 있는 문제 | 별도 화면 검수 기능 | 현재 발언 후보 보충 경로로 전체 화면 검수를 보장하지 않음 |

국가·지역명과 한적한 배경을 결합했다고 자동 비하가 되지 않는다. 예를 들어 공간을 보고 국가를 묻는 발언에서 이미지는 공간의 사물·표시를 보충할 수 있지만, 그것만으로 경멸 의도나 특정 국가를 낮춰 보는 의미를 증명하지 못한다.

## 실제 프롬프트 변경

사용자가 이미지 호출 정책도 다듬도록 요청하여, 이전 동결의 **시각 분기 두 부분만** 수정했다.

1. `CandidateReviewPrompts.DISCOVERY_PROMPT`의 visualCandidates 선별 문단을 교체했다.
   - 필요한 화면 사실과 그 사실이 해석을 바꾸는 이유를 reason에 작성.
   - 텍스트로 충분한 후보는 텍스트 경로 유지.
   - 원음·연속 행동만으로 해결할 누락은 uncertainSegments로 구분.
2. `VisualContextReviewer.PROMPT`의 관측 지침을 교체했다.
   - 선택 프레임에서 보이는 사실 → 발언과 연결 → 남은 불확실성을 분리.
   - 표정·국가·의도·음성 추정 금지, 작은 글자는 추측하지 않기.
   - 프레임 밖 사실과 연속 장면을 만들지 않기.

후보 엔진 개정은 `2026-10-23-candidate-visual-necessity-47`이다. 공용 POLICY·텍스트 VERIFICATION_PROMPT, 사례 정답·운영 사전·이미지 수·모델·출력 JSON 구조는 바꾸지 않았다. 재시작 후 새 분석부터 적용되며 이번 작업에서 서버를 재시작하거나 유료 호출하지 않았다.

이번 변경은 **LLM에게 주는 호출 선별 지침**이다. 서버가 이미지 필요성을 의미적으로 검증하는 새 하드 게이트를 구현한 것은 아니다. 후보가 과도하게 생성될 가능성은 남는다. 실제 호출 수·오탐·미탐·시간 개선은 아직 측정하지 않았다. 시각 경로는 여전히 업로드 영상만 지원하며 YouTube URL의 VISUAL_UPLOAD_ONLY 제한을 해결한 작업이 아니다.

## 출처와 한계

OpenAI Docs의 [Images and vision](https://developers.openai.com/api/docs/guides/images-vision)은 작은 글자·비라틴 문자·공간 판단·잘못된 묘사 가능성 등의 한계를 설명한다. 이 문서는 이미지 입력의 한계를 확인하는 데 참고했으며, 특정 모델의 현재 계정 접근성·가격이나 우리 서비스의 정확도를 검증한 자료는 아니다.

실제 프롬프트 전문은 [요청별 전문](현재-AI-요청별-프롬프트-전문.md)과 [검색 보충 전문](../casebook/사례-검색-프롬프트-전문.md)을 코드 스냅샷 테스트와 함께 유지한다.

## 무료 검증

이미지 요청 모의 검사·시각 필요조건 문구·전문 스냅샷과 전체 Java 회귀1167개가 통과했다(실패/오류/skip0). 기존 문구를 고정 검사하던 테스트1개는 교체한 호출 필요조건을 검사하도록 갱신했다. Python tools167개 통과·선택적6개skip을 확인했다. 실제 모델 응답이나 호출 감소를 측정한 테스트는 아니다.

이전 동결267개 중 변경은 시각 분기 소스2개와 개정 문자열이 있는 엔진1개뿐이다. POLICY·텍스트 VERIFICATION_PROMPT의 소스 문자열은 이전 커밋과 같음을 별도로 대조했다. 이전 freeze 파일을 새 기준으로 덮어쓰지 않았다.
