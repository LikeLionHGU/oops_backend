# 판단 기준 비교안41 결과 — 채택 보류

2026-10-15. 사용자에게 새 추정 $1 이하와 해당 텍스트의 OpenAI 전송을 승인받았다.
이전 예산은 재사용하지 않았다. **72회 완료했지만41은 채택하지 않는다.**
실제66 공방은 여전히 경고하고, 지역 흐름은 이번 비교에서 기준선2/3 검토·41은0/3이었다.
소수 반복이므로 통계적 퇴행을 확정하는 것은 아니지만 운영 교체의 근거가 되지 않는다.

## 실제 영상 기반 네 조건

각 안3회이며 경고 카드 발행 수가 아니라 고정 후보의 계약 검증 후 판정이다.

| 조건 | 기준선39 | 수정안41 |
|---|---|---|
| 64 지역 선택지 흐름 | 검토2·PASS1 | PASS3 |
| 64 신체 훼손 비유 | 검토3 | 검토3 |
| 65 정상 제품 리뷰 | PASS3 | PASS3 |

66의 기준선 계약 실패2건은 TARGET_EVIDENCE_REQUIRED다. 정상 PASS로 세지 않았다.
41의 첫 응답은 장난 가능성을 인정하면서도 “원문만으로 합의를 확인할 수 없어 검토가 필요하다”고 설명했다.
합의를 상상하지 말라는 지시가 합의 증거 부재를 공격의 근거로 쓰는 결과로 이어질 수 있다는 **관찰**이다.
프롬프트만이 유일한 원인이라고 확정하지 않는다. 화자/억양이 없는 입력 한계도 여전히 남는다.
지역 흐름의 불명확 STT ‘반산두종’은 이번에도 원문 그대로다. 새 기준선 결과가 이전40의 기준선과도 달라
단 한 번의 성공을 안정화라고 부를 수 없다.

## 합성 대조 여덟 조건

대사별 독립 정답 검수 전 개발 관찰이다. 아래 ‘검토’는 계약을 통과한 REVIEW_REQUIRED다.

| 조건 | 기준선39 | 수정안41 |
|---|---|---|
| 문맥 없는 단독 표현 | UNCERTAIN3 | UNCERTAIN3 |
| 구체적 행동의 강한 비판 | PASS2·계약 실패1 | PASS1·계약 실패2 |
| 사람 자체의 가치 폄하·배제 | 검토3 | 검토3 |
| 게임 속 상호 공방 | PASS3 | PASS3 |
| 중단 요청 뒤 외모 공격 | 계약 실패3 | 계약 실패3 |
| 인용한 인격 공격을 비판 | PASS3 | PASS2·계약 실패1 |
| 인용한 공격에 동조·배제 | 검토3 | 검토3 |
| ‘장난이야’만 덧붙인 표현 | UNCERTAIN3 | UNCERTAIN3 |

외모 공격은 양쪽 모델 응답 모두3/3 REVIEW_REQUIRED였지만 targetMention은 ‘네 얼굴’,
target은 ‘가의 얼굴’ 등의 설명형 명칭인데 targetRelation을 EXPLICIT으로 반환해 TARGET_MENTION_RELATION으로 거절됐다.
현재 계약에서는 지칭 문자열과 설명형 대상이 다르면 CONTEXTUAL 및 별도 연결 근거가 필요하다.
이를 모델이 공격을 이해하지 못한 경우나 정상 판정으로 집계하지 않는다. 자동 수정·복구는 이번 통제에서 제외했다.
행동 비판과 인용 비판의 실패4건은 모델이 PASS라고 답했으나 alternativeInterpretation을 null로 남긴
LINKED_PASS_CONTRAST_REQUIRED다. 이유 필드에는 정상 해석이 있어도 현재 계약상 별도 필드가 필수다.

두 안 모두 전체36건 중 유효 검토12/PASS12/UNCERTAIN6/계약 실패6이다.
총계가 같아도 지역 미탐·공방 경고·실패 위치는 달라 단순 통과율이나 경고 수만으로 비교하지 않는다.

41을 기본 경로에 붙이지 않고 현재39/기본37을 유지한다. 같은 문단에 예외를 더 붙이는 작업부터 반복하지 않는다.

## 비교 설계

- 기준선: 운영 POLICY를 사용하는 관계39 최초 검증 요청. 비교: 같은 POLICY의 정상 해석 문단만41로 교체.
  지난40과41을 비교하는 시험이 아니다. [교체 전문](농담-인격공격-대조-검수.md)을 따른다.
- 실제 저장 전사 기반4조건 + 합성8조건, 두 안×각3회 = 72회 계획이다.
  홀수 반복은 기준선 먼저, 짝수 반복은 비교안 먼저다. 무작위 독립 블라인드 시험이 아니다.
- 실제4조건은 이전40 plan의 원문·후보·기준선·참고를 그대로 사용한다. 64지역/64신체 비유/65리뷰는 기존 개발 기대값,
  66은 영상 수준 정상 피드백을 보존하되 발췌만의 확정 정답으로 점수화하지 않는다.

  대사별 독립 검수가 완료된 정답이 아니며 합성 정상률을 범용 정확도라고 부르지 않는다.
