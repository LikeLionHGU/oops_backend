서비스는 이 대목을 후보로 올리지 않았다. 전사에서 핵심 말이 빠진 것은 아니지만 검증 호출도 없으므로 '검증이 PASS로 탈락시켰다'고 해석하지 않는다. LF01은 assistant의 검토 후보이고 사용자 정답은 아직 없으므로 확정 미탐 수치로 집계하지 않는다. 후보로 뽑지 않았다는 것만으로 의미 이해가 성공했거나 정상으로 판정했다고 보지도 않는다.

LF02·03·04·06의 정상 초안 대목에도 경고 카드는 없다. 하지만 후보0은 각각에 대한 명시적인 PASS 설명이 아니고, 사용자 승인 정상 정답도 아니므로 정상 정확도로 세지 않는다. LF05의 제3자 문서 노출 가능성은 장면 확인이 없어 미평가로 남긴다.
