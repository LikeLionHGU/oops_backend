# 맥락 검색 승격 판정·기준선 — 2026-10-23

> 이전 보류 판단 기록이다. 이때1~5단계를 전체 완료로 처리한 것은 정정했다. 현재 구현·검증은 [운영 연결 후속](맥락검색-운영연결과-저장문맥-검증-20261023.md)을 따른다.99/109는 각각39/41참고 당시의 과거 관측이며 현재43참고에서도 실패한다고 단정할 수 없다.

## 결론

마지막 한 슬롯 보완은 **운영 승격 보류**다. 폐기하거나 새 기본 OFF 기능으로 추가하지 않는다. 운영43참고와 공용 판단 프롬프트, 기존 검색을 유지한다.

개발44참고에서 새 경계 참고의 회수가 좋아졌지만, 현재 운영43참고에는 그 새 경계 참고가 없다. 다른 소재의 기존 사용자 승인 자료3개는 필요한 참고가 이미 선택됐다. 현재 자산에서 개선 이득을 확인하지 못했으므로 운영 연결과 변경 효과를 주장하는 유료 비교를 강행하지 않는다.

## 1~5 단계 처리

| 단계 | 처리 | 근거/한계 |
| --- | --- | --- |
| 1. 다른 소재 기준 고정 | 완료 | 학원 피해 경험 전달, 시청자 노력 평가, MT 성향 설명. 기존 승인 문맥만 사용. 별도 원영상3개지만 모두 미미미누 개발 자료이며 독립 평가가 아님 |
| 2. 시안 채택 결정 | 완료·승격 보류 | 다른 소재의 기대 참고 추가 회수>0, 기존 참고 손실0, 무관 추가0, 크기 위반0을 문턱으로 설정. 추가 회수0으로 미충족 |
| 3. 통과하면 운영 연결 | 미실행 | 채택 문턱을 통과하지 못했으므로 조건부 단계 중단. 운영 코드에 새 검색 경로/플래그를 넣지 않음 |
| 4. 실제 영상 최종 카드 검증 | 기존 저장 결과 확인만 수행 | 새 운영 경로·새 모델 결과 없음. 저장 카드의 오류가 해결됐다고 주장하지 않음. 선택 변화가 없어 새 유료 전후 비교를 수행하지 않음 |
| 5. 기준선 동결 | 완료 | 소스·자료·runtime 해시와 기대 참고/선택 전후·승격 결정을 private manifest로 기록 |

‘단계 처리 완료’와 ‘기능 개선·운영 적용 완료’를 구별한다. 새 정확도 성적표를 만든 것이 아니며 전체 분석 안정화를 완료한 것도 아니다.

## 고정된 검색 평가

`ContextFitAdoptionGateTest`가 runtime·원장·저장 전사 SHA256과 기존 개발 승인 범위를 확인한다. 사용자 라벨은 판단 프롬프트 입력에 넣지 않으며 외부 호출은 없다. 기대 참고는 해당 원장의 ID로 선언한다. ID를 검색 점수에 사용하지 않는다.

| 자료 | 기존 승인 | 운영 검색 전후 |
| --- | --- | --- |
| 학원 피해 경험 회고 | PASS | 피해 경험 참고1개 유지 |
| 플래너 설명 중 시청자 노력 평가 | REVIEW_REQUIRED | 시청자 평가 참고1개 유지 |
| MT 성향·취침·나이 설명 | PASS | MT 성향 참고1개 유지 |

세 입력 모두 선택 목록이 완전히 같아 참고 추가·손실·크기 증가가 없다. 이 경우 무관 추가0은 의미 분류기의 정확도 평가가 아니라 ‘아무 참고도 추가하지 않았다’는 검사다. 별도 합성 경계의 정답을 새로 승인하지 않았다.

private 고정 기록: `datasets/controversy/experiments/context-fit-adoption-decision-freeze-20261023.json`. 최초 중간 검사 `context-fit-adoption-gate-20261023.json` 대신 이 결정 기록을 현재 기준으로 사용한다. 민감 원문이나 자료 자체는 Git에 넣지 않는다.

## 저장 카드와 남은 오류

98번 저장 카드0개,99번0개,109번1개를 확인했다.99번의 사용자 승인 검토 문맥 누락,109번의 사용자 승인 정상 문맥 경고는 과거 관측으로 남는다. 이번 검색 회수 검사로 해결된 것이 아니다.98번0개 역시 영상 전체 정상 또는 현재 코드 성능의 증거가 아니다.

같은 참고가 회수돼도 후보 탐색·검증이 적절한 최종 결정을 내리는 것은 별개다. 다른 실행 버전의 보고서에 현재 소스 해시를 소급 적용하지 않는다. 기록에는 `historicalOnly=true`, `reanalysisPerformed=false`를 명시한다.

## 비용·실행 범위

이번 목표에서 새 추정$1.00 및 저장 텍스트 전송 승인을 받았으나 유료 호출은0회다. 같은 선택 결과로 불필요한 ON/OFF 반복을 만들지 않았다. 미사용 승인을 후속 시험 예산으로 자동 이월하지 않는다. 서버 재시작·새 영상 다운로드·영상/음성 전송·배포는 하지 않았다.

## 재개 조건

새 경계 묶음을 검수해 운영 자산으로 승격할 근거를 마련하거나, 다른 소재에서 ‘후보에는 있지만 필요한 경계 참고가 밀리는’ 실제 사례를 확보했을 때 재개한다. 이번3조건을 맞히려고 무관 키워드나 사례별 예외를 붙이지 않는다.

현재99/109의 후속 분석 개선은 별도 작업이다. 현재 코드로 고정된 저장 문맥·후보·선택 참고를 검증하는 작은 비교를 설계하고, 탐색 누락과 제공된 근거의 판단 오류를 구별해야 한다. 이번 결과를 검색 시안의 성능 향상으로 포장하지 않는다.
