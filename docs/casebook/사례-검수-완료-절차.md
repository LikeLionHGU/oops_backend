# 사례 검수부터 영향 비교까지

이 절차는 연구 사례 하나를 끝까지 다루기 위한 작업 기준이다. 사례 등록, 개발 비교, runtime 반영, 독립 평가는 서로 다른 상태이며 앞 단계의 완료가 뒤 단계의 승인을 뜻하지 않는다.

1. **관찰 기록:** 출처와 접근 시점, 원음·화면 자막·전사·댓글·해석을 구분한다. 스크립트 항목 시각은 발화 경계와 구분하고, 언어와 생성 방식은 확인된 범위만 기록한다. 완료: 각 핵심 근거의 출처와 확인 방식이 있고 추정은 추정으로 표시된다.
2. **판단 경계:** 상황·대상·행위·연결과 검토 이유, 가까운 정상 해석을 정리한다. 미확인이 판정을 바꿀 수 있다면 판단을 보류하고, 부가 정보만 부족하면 미확인으로 남긴다. 완료: 사람의 판단과 그 범위 또는 보류 이유가 기록된다.
3. **사례 추가안:** 기존 메커니즘 보강인지 새 경계인지 구분하고 출처 이용 범위를 용도별로 확인한다. 원문이 없는 자료는 보도·요약 출처를 원음 전사로 바꾸지 않는다. 완료: 사례 초안과 기존 기준에 미치는 변경이 명확하며, 등록은 운영 반영과 구분된다.
4. **무료 영향 검사:** 동결한 기존 사례와 가까운 정상 대조에서 검색 회수, 기존 참고 밀림, 입력 크기, 빌드 재현성을 비교한다. 같은 출처 재검색은 연결 검사이며 일반화 증거가 아니다. 완료: 기준선과 후보의 결과·실패·미실행 항목이 남는다.
5. **필요한 경우 모델 비교:** 목적·입력·전송 대상·비용·중단 기준을 묶어 승인받고 이전 예산을 재사용하지 않는다. 목표 오류와 정상 대조 회귀를 함께 확인해 채택·보류·폐기를 기록한다. 완료: 결정과 근거가 남으며, 다른 출처의 독립 평가는 별도 상태로 유지된다.

출처 확인은 열람, 다운로드, 로컬 보관, 외부 모델 전송, runtime 검색, 학습·재배포를 구분한다. 미확인은 허가도 금지도 뜻하지 않는다. 사용자 승인과 출처별 이용 가능성은 별도로 확인하며, 승인된 범위 안에서는 동일한 질문을 반복하지 않는다. 기존 동결 사례의 해시 통과는 권리 확인이나 품질 인증이 아니다.
