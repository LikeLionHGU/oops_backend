## 다음 문서 구조 정리안

현재 파일 경로는 링크·코드 참조 보호를 위해 유지했다. 다음 단계에서는 참조를 함께 갱신하며 아래처럼 분류한다.

- `guides/`: 현재 실행·아키텍처·API·보안·분석 정책.
- `casebook/`: 사례자산 설계·정본 관리·검색 운영.
- `reviews/`: 영상별 사전 관찰·사용자 검수·승인 기록.
- `experiments/`: 비교 시험·측정·코드 정비 결과.
- `archive/`: 대체된 설계와 과거 상태 일지.

개별 사례가 늘 때마다 안내 문서에 긴 결과를 붙이지 않는다. 현재 상태는 짧게 갱신하고 상세 근거는 해당 기록에 연결한다. 파일 삭제·중복 본문 통합은 참조와 고유 근거를 확인한 뒤 별도로 진행한다.
