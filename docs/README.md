- Spring Boot + Python FastAPI 구조와 기존 배포 방식은 유지한다. Rails 8 마이그레이션·영속 큐·로그인·편집 기능은 구현 완료가 아니다.
- 텍스트 모델 기본값은 Luna, STT는 whisper-1이다. 구간과 대화 묶음을 독립 호출에서 판정하고 기존 근거 검증을 적용한다. 이전 Java 195개 등 단계별 테스트 수는 당시 기록이며 독립 영상 정확도를 뜻하지 않는다.
- ID 9 이후 신체 훼손 비유/표현 연결 예외·대조 해석 필수 검증·묶음 인용 오류 세분화를 반영했다. 당시 Java 220개 통과, ID 10에서 새 유형 카드 반환 확인, 이후 범용 비교 단계에서 236개 통과다. 독립 평가와 새 category 값의 프론트/운영 DB/롤백 호환 점검은 남아 있다.
- ID 12는 53구간 유효 판정, 묶음 5개 중 3개 유효(보류 1 포함)/2개 탈락, C/D 카드 2개, 117.5초다. B는 PASS와 창 밖 인용 탈락으로 나뉘며 추가 대상 누락 오류가 있다. [실험 기록 20절](AI-분석-실험-기록.md)이 최신 결과다.
- 로컬 진단은 메모리 임시 자료다. local 프로필 활성화가 접근 인증을 제공하지 않으므로 반드시 루프백 바인딩하고 공개 서버에서는 끈다.
- HyperFrames/PostHog는 공식 자료 조사와 적용 설계만 작성했다. 설치·계정 개설·외부 데이터 전송·운영 배포는 하지 않았다.

## 중복을 막는 관리 규칙

- 구현 완료, 코드 반영 후 실사례 검증 대기, 제안, 과거 기록을 명시한다. 배포 환경은 코드의 기본값과 구분한다.
- 데이터 수량·라벨·분할·주석 기준은 논란 데이터셋 문서에서 관리한다. 다른 문서는 상세 내용을 다시 복사하지 않고 링크한다.
- AI 구현 순서는 AI 분석 개선 계획, 전체 일정과 인프라 우선순위는 향후 개발 계획을 기준으로 한다.
- 가상 예문·모의 응답·사후 기사·사용자 액션을 독립 평가의 정답으로 간주하지 않는다.
- 프롬프트·설정의 실행 기준은 코드다. 전문을 수정할 때는 원본 코드와 함께 대조하고 확인 시점을 기록한다.
- 과거 기록은 최신 설정·성능·작업량·운영 대응의 근거로 쓰지 않는다. 유료 실행·계정 개설·자료 다운로드는 문서의 제안만으로 수행하지 않는다.
