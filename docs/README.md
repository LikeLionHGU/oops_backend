## 중복을 막는 관리 규칙

- 구현 완료, 코드 반영 후 실사례 검증 대기, 제안, 과거 기록을 명시한다. 배포 환경은 코드의 기본값과 구분한다.
- 데이터 수량·라벨·분할·주석 기준은 논란 데이터셋 문서에서 관리한다. 다른 문서는 상세 내용을 다시 복사하지 않고 링크한다.
- AI 구현 순서는 AI 분석 개선 계획, 전체 일정과 인프라 우선순위는 향후 개발 계획을 기준으로 한다.
- 가상 예문·모의 응답·사후 기사·사용자 액션을 독립 평가의 정답으로 간주하지 않는다.
- 프롬프트·설정의 실행 기준은 코드다. 전문을 수정할 때는 원본 코드와 함께 대조하고 확인 시점을 기록한다.
- 과거 기록은 최신 설정·성능·작업량·운영 대응의 근거로 쓰지 않는다. 유료 실행·계정 개설·자료 다운로드는 문서의 제안만으로 수행하지 않는다.
