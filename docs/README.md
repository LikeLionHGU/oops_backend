## 현재 상태

- 10/10 코드리뷰 보완: STT 선택 표현 98개 표기·별도 저장/API, 키워드만으로 맥락 카드 발행하던 경로 제거, 결과/완료 원자적 저장, 오류 분리·경고 누적·분석기별 버전 표시를 적용했다. 프론트/운영 배포는 미적용이다.

- 구현: 후보 탐색 → 근거 검증, 개정 `2026-10-10-candidate-reference-repair-26`. 맥락 사전 v4는 유지하고 후보 인용 우선 선별·같은 참고 구성의 후보 묶음·잘못된 ID 한정 복구(영상당 최대 2회)를 추가했다. 호출·총비용은 늘 수 있다.
- 검증: Java 463개·분석 서버 Python 57개·도구 Python 95개 통과. 이전 저장 전사 감사의 참고 JSON 약 39% 감소는 개정 25 탐색 입력 기준이며 새 전체 토큰·비용·탐지 개선 수치가 아니다.
- 최신 실영상: ID 33은 개정 25/v4에서 D만 발행했다. B는 PASS, C는 근거 ID 오류로 탈락했다. ID 32의 개정 24 B/C/D 3개보다 악화됐고 새 개정 26 결과는 대기 중이다.
- 데이터: 6사건·9카드·30매핑 반응·518개 고유 댓글 표본을 바탕으로 작업 참고 파일을 만들었다. 사람 승인·실제 정상 대조는 0개이며 파인튜닝 완료 데이터가 아니다. 원장은 Git 제외다.
- 신규 설계: **맥락 검수 + 선택형 표현 자체 탐지**. 욕설/커뮤니티·논쟁 표현 등장 목록과 프론트 필터는 아직 구현하지 않았다.
- 보류: 포즈·행동 분석, 편집 기능, Rails 전환, 마인드맵 그래프 UI. Spring Boot + Python 및 기존 배포 방식 유지.

상세 변화와 ID별 결과는 [실험 기록](AI-분석-실험-기록.md)에만 누적한다. 과거 결과를 이 안내에 반복 복사하지 않는다.

- `논란-댓글-수집-진행.md`와 `문맥-논란-사례-파일럿.md`는 [댓글 수집·파일럿 기록](archive/댓글-수집-및-문맥-파일럿-기록.md) 하나로 통합했다. 수집 경위·출처·기한·미확보 정보는 삭제하지 않았다.
- 오래된 `사용중인-프롬프트-전문.md`는 [과거 프롬프트 스냅샷](archive/사용중인-프롬프트-전문.md)으로 옮겼다. 현재 전문과 혼동하지 않는다.

- SQL 마이그레이션은 실행 자료이므로 문서 통합 대상으로 삭제하지 않는다.

## 관리 원칙

현재 구조는 AI 분석 로직, 사전 계약은 범용 기준집, 표현 필터는 표현 탐지 설계, 실행 결과는 실험 기록을 단일 기준으로 관리한다. 나머지는 상세 설계/운영 또는 과거 근거다. 코드·데이터·API가 바뀌면 해당 기준 문서와 링크를 함께 갱신한다.

설계 필드/가상 예문을 실제 API나 검수 정답으로 표시하지 않는다. 이전 기록에는 당시 버전을 명시한다. local 진단은 인증을 제공하지 않으므로 루프백에서만 사용하고 공개 운영에서 끈다. 문서의 제안만으로 유료 호출·배포·외부 전송을 수행하지 않는다.
