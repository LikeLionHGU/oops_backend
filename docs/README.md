## 기록 원칙

사건 원장·전사·모델 응답·댓글은 비공개 `datasets/**`에 두고, 문서와 재현 도구만 Git으로 관리한다. 원문과 모델 해석, 사용자 승인과 검수 초안, 모델 판단과 출력 계약 통과를 구별한다. 카드 수 감소나 사전 로드 성공만으로 정확도 향상을 주장하지 않는다.

같은 사건을 참고한 개발 재현과 제외 family를 지정한 독립 평가를 구분한다. 변경 전후의 원문·사전·요청·응답 해시와 미판정 상태를 보존한다. 과거 예산·사용량 추정·실제 청구는 서로 다른 값이다.
