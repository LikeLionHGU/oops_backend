primary/context ID 반환 범위는 후속 코드에 반영했다. 검토·대표 ID는 primary, 근거·관계 ID는 raw 전체로 제한한다. 후속 실호출 32회에서 정상 초안은 양쪽 12/12 완전 무경고, 범위 오류도 양쪽 0건이었다. 제한 추가의 개선 효과는 입증하지 못했고 SCOPED는 후보·비용이 더 늘었다. 다음 순서는 **원문 행위·대상 연결 보존 → 문맥 제한 PARTIAL 진단 → 집단 일반화 경계 검수**다. 전체 업로드 리포트·범용 정확도 검증과 구별하며 정상 초안은 정식 사전 미승격이다.

행위·대상 보존의 고정 검증 비교는 56회 완료했다. 정상 초안 양쪽 12/12 PASS·계약 통과, 전체 계약 통과 이전 24/28·수정 22/28이며 의미 우위도 입증하지 못해 수정 지침은 운영에 반영하지 않았다. 설정 단가 추정 $0.01872430으로 새 승인 $0.50 안에서 완료했다. 다음은 탐색 축이 최종 검증을 제한하는 계약과 대상 인용의 의미 정합성 점검이다. 자세한 결과·해시는 [출력 계약·후속 비교 문서](탐색-출력계약-JSON-스키마-비교.md)의 마지막 절을 따른다.

후속 [최종 판단 근거 분리](최종-판단-근거-분리.md)는 무료 856개·고정 검증 실호출 56회 완료 상태다. 계약 통과는 기존 24/28·새 계약 25/28이나 정상 초안 완전 처리는 12/12·11/12이며 실제 질문의 경고→PASS 변화와 자기 제안의 판단 흔들림이 남았다. EXPRESSION_CONTENT 응답은 없었다. 추정 비용 $0.01956624, 의미 우위는 미입증이라 `FINAL_REVIEW_BASIS_ENABLED=false`를 유지한다. 전체 탐색·복구·카드 효과는 별도이며 다음은 실제 발췌 경계 검수와 계약/판단 지침 분리 설계다.

후속 [JSON/strict 실제 비교](탐색-출력계약-JSON-스키마-비교.md)는 검색 ON 고정·호환 시험 1회·본 비교 32회를 완료했다. 정상 초안 완전 무경고는 JSON 10/12·STRICT 12/12이고, 탐색 `truncated` 누락은 2/18→0/18이었다. 설정 단가 추정 합계 $0.01465401로 완료하고 `STRUCTURED_DISCOVERY_OUTPUT_ENABLED` 기본 true를 채택했다. 실제 발췌의 범위 오류·의미 변화는 남으며, 누락값 자동 보정이나 실패의 정상 치환은 하지 않는다. 서버는 재시작하지 않았다.

## 기록 원칙

사건 원장·전사·모델 응답·댓글은 비공개 `datasets/**`에 두고, 문서와 재현 도구만 Git으로 관리한다. 원문과 모델 해석, 사용자 승인과 검수 초안, 모델 판단과 출력 계약 통과를 구별한다. 카드 수 감소나 사전 로드 성공만으로 정확도 향상을 주장하지 않는다.
