## 최신 결과와 다음 작업

[Groq 전사 후속 점검](Groq-전사-후속-점검.md)에서 v4·v6를 재전사하고 같은 시간대 발췌 5쌍과 정상 초안 6개를 비교했다.

- 전사: v4 핵심 질문의 오류와 반복 구간 일부가 개선됐고 줄임말 오류는 남았다.
- 회수: 새 대본에서도 사생활 질문·죽음 표현 구간의 관련 사례가 0개 선택됐다.
- 정상 대조: 4개 SUCCESS, 2개는 필수 Boolean 누락으로 FAILED. 정식 사전에는 미승격이다.
- 검증: 죽음 표현 후보의 대상 관계 계약 탈락과 집단 전체 표현의 후보 중심 이동을 확인했다.

후속 [구조화 검색 보완](맥락사전-구조화검색-보완.md)은 같은 16조건·23검색 창을 무료 비교했다. 속옷 질문의 관련 참고 0→3개, 집단 전체 표현의 참고 교체를 확인했고 정상 초안 6조건은 선택이 같았다. 죽음 표현은 여전히 참고 0개다. 검색 개선과 최종 판단 정확도는 다르다.

후속 [정상 경계·최종 판단 비교](구조화검색-OFF-ON-정상경계-비교.md)는 합성 초안 6개·실제 발췌 2개의 OFF/ON 각 2회, 총 32회를 완료했다. 정상 초안 경고는 양쪽 0이지만 완전한 무경고 처리는 OFF 11/12, ON 8/12였다. 나머지 5건은 필수 Boolean 미반환 실패다. 속옷 질문은 양쪽 유지됐으나 추가 경고의 행위 방향 변화, 집단 전체 표현의 후보 이동·PASS가 남았다. 추정 비용은 $0.019863이다.

primary/context ID 반환 범위는 후속 코드에 반영했다. 검토·대표 ID는 primary, 근거·관계 ID는 raw 전체로 제한한다. 후속 실호출 32회에서 정상 초안은 양쪽 12/12 완전 무경고, 범위 오류도 양쪽 0건이었다. 제한 추가의 개선 효과는 입증하지 못했고 SCOPED는 후보·비용이 더 늘었다. 다음 순서는 **원문 행위·대상 연결 보존 → 문맥 제한 PARTIAL 진단 → 집단 일반화 경계 검수**다. 전체 업로드 리포트·범용 정확도 검증과 구별하며 정상 초안은 정식 사전 미승격이다.

행위·대상 보존은 현재 비교 준비 단계다. 테스트 전용 지침과 고정 검증 요청 14조건을 만들었고 이전/수정 각 2회, 총 56회 계획을 생성했다. 보수적 예약 추정 $0.35863360, 새 $0.50/텍스트 전송 승인 대기이며 실호출·운영 프롬프트 반영은 아직이다. 후보 재탐색을 빼고 원문·후보·참고를 고정해 의미 변화와 형식 탈락을 따로 확인한다. 자세한 지침·계획 해시는 [출력 계약·후속 비교 문서](탐색-출력계약-JSON-스키마-비교.md)의 마지막 절을 따른다.

후속 [JSON/strict 실제 비교](탐색-출력계약-JSON-스키마-비교.md)는 검색 ON 고정·호환 시험 1회·본 비교 32회를 완료했다. 정상 초안 완전 무경고는 JSON 10/12·STRICT 12/12이고, 탐색 `truncated` 누락은 2/18→0/18이었다. 설정 단가 추정 합계 $0.01465401로 완료하고 `STRUCTURED_DISCOVERY_OUTPUT_ENABLED` 기본 true를 채택했다. 실제 발췌의 범위 오류·의미 변화는 남으며, 누락값 자동 보정이나 실패의 정상 치환은 하지 않는다. 서버는 재시작하지 않았다.

## 기록 원칙

사건 원장·전사·모델 응답·댓글은 비공개 `datasets/**`에 두고, 문서와 재현 도구만 Git으로 관리한다. 원문과 모델 해석, 사용자 승인과 검수 초안, 모델 판단과 출력 계약 통과를 구별한다. 카드 수 감소나 사전 로드 성공만으로 정확도 향상을 주장하지 않는다.

같은 사건을 참고한 개발 재현과 제외 family를 지정한 독립 평가를 구분한다. 변경 전후의 원문·사전·요청·응답 해시와 미판정 상태를 보존한다. 과거 예산·사용량 추정·실제 청구는 서로 다른 값이다.
