# OoPs?! 문서 안내

> 2026-10-13 · minwook · 저장소 기준. 코드 반영, 실제 분석 확인, 설계, 과거 기록을 구분한다. AWS 배포 상태를 확인한 문서는 아니다.

## 현재 상태

- 최신 완결 시험은 [150: 고정 입력 반복성](AI-분석-실험-기록.md)이다. 같은 버전의 B/C/D 각 검토 6/6·정상 PASS 36/36·Java 계약 54/54를 확인했다. 충실한 사건 카드·현재 기준점·저장 순서·필수 PASS 대조 예시·시험 3,000 상한을 함께 동결했다. 고정 입력 gate 통과이지 자동 SELECT/전체 영상/독립 의미/운영 안정화 승격은 아니다. 부연의 불필요한 관계 추정 1건은 의미 검수에 남겼다.
- 시험 도구의 변경과 운영 코드를 구분한다. 기본 판단 개정 33·사전 v4·Spring Boot + Python·기존 배포는 유지한다. v5 검색/판단 view 분리와 충실한 사건 카드는 명시적으로 선택한 private 시험본이다. 자동 SELECT·전체 영상 재분석·AWS 배포·학습 승격은 확인하지 않았다.
- 분석 기본 경로는 맥락·표현 검수다. 외부 검색은 선택 프로필 external-review에 분리했고, 욕설/논쟁 표현 등장 목록은 별도 저장/API로 제공한다. 결과/완료 원자적 저장·오류 분리·경고 누적·검증 인용 기반 병합은 유지한다. 프론트 표현 필터, 포즈/행동 분석, 편집 기능, Rails 전환, 마인드맵 UI는 후속/보류다.
- 서버 안전성 구현은 [코드 정리](코드-정리-및-안전성-개선.md)를 따른다. 업로드 준비는 DB 밖, 등록/atomic rename은 짧은 트랜잭션, 분석 접수는 health 확인 뒤 잠금 재검사·bounded 실행이다. 시작 복구는 단일 인스턴스용이며 공유 DB의 다중 Spring에서는 꺼야 한다. 영속 큐/분산 소유권·고아 업로드 수거는 후속이고 프레임 수거는 기본 OFF다.
- request-traces는 기본 OFF·local/loopback·별도 토큰·크기/건수/보존 시간 제한이 있다. 실제 provider 요청/응답을 민감 자료로 관리하며 로그/DB/외부 자료를 자동 승인 정답으로 보지 않는다. [실제 요청 기록](성공-버전-회귀-비교.md#로컬-실제-요청-기록--구현-새-영상-검증-대기)을 따른다.
- 데이터 원장/실험 JSON은 Git 제외다. 과거 6사건·9카드·30반응 매핑·518댓글 표본은 당시 작업 참고 자료이지 학습 완료 데이터가 아니다. 사용자 개발 라벨, assistant 관찰, 독립 의미 승인, 운영 승인 상태를 구분한다. 알려진 원사건 재현을 독립 영상의 범용 정확도로 발표하지 않는다.
- 예산은 승인별 별도 원장에서 예약을 누적한다. 최근 추가 $1 승인은 145/146과 후속 비교용이며 이전 잔액과 합치지 않는다. 사용량 환산/예약/실제 청구를 구분하고 최신 값은 [실험 기록](AI-분석-실험-기록.md)에만 기록한다.
- 상세 결과와 과거 ID/버전/예산은 [실험 기록](AI-분석-실험-기록.md)에 누적한다. 이 안내에는 현재 상태만 두며 과거의 여러 ‘최신’을 반복하지 않는다.

## 이번 정리와 과거 기록

- 기존 README의 중복 ‘최신’ 업데이트를 제거하고 현재 상태와 문서 책임으로 통합했다. ID별 실험 원문은 보존했다.
- `논란-댓글-수집-진행.md`와 `문맥-논란-사례-파일럿.md`는 [댓글 수집·파일럿 기록](archive/댓글-수집-및-문맥-파일럿-기록.md) 하나로 통합했다. 수집 경위·출처·기한·미확보 정보는 삭제하지 않았다.
- 오래된 `사용중인-프롬프트-전문.md`는 [과거 프롬프트 스냅샷](archive/사용중인-프롬프트-전문.md)으로 옮겼다. 현재 전문과 혼동하지 않는다.
- [초기 현황·인수인계](archive/초기-프로젝트-현황-및-인수인계.md), [과거 기획·구현 대조](archive/기획-대조-및-구현-검증-기록.md)는 이력으로 보존한다.
- SQL 마이그레이션은 실행 자료이므로 문서 통합 대상으로 삭제하지 않는다.

## 관리 원칙

현재 구조는 AI 분석 로직, 사전 계약은 범용 기준집, 표현 필터는 표현 탐지 설계, 실행 결과는 실험 기록을 단일 기준으로 관리한다. 나머지는 상세 설계/운영 또는 과거 근거다. 코드·데이터·API가 바뀌면 해당 기준 문서와 링크를 함께 갱신한다.

설계 필드/가상 예문을 실제 API나 검수 정답으로 표시하지 않는다. 이전 기록에는 당시 버전을 명시한다. local 진단은 인증을 제공하지 않으므로 루프백에서만 사용하고 공개 운영에서 끈다. 문서의 제안만으로 유료 호출·배포·외부 전송을 수행하지 않는다.
