### 확인된 오류와 아직 정하지 못한 정답 범위

**확인:** 뜻 질문165가 실제 모델 입력에 있었다. 최신 기본 경로의 두 안×두 반복, R01 네 응답은 모두 경고·계약 통과였다. 이유는166을 ‘상대 속옷을 묻는 실제 사적 질문’으로 기술하고 뒤 제안에 연결했다. 뜻풀이 해석을 충분히 대조하지 못했다. 맥락 줄 미제공이나 계약 필드 누락만의 문제는 아니다.

**아직 미확정:**32줄 전체의 최종 PASS를 기존5줄 인용 승인과 동일 범위로 볼 수 있는지, R01 카드가166의 발화 행위를 검토하는지 뒤178의 제안까지 포함한 별도 쟁점을 검토하는지다. 후반 농담에 독립 검토 이유가 있는지와166이 실제 질문인지 여부는 다른 질문이다. 하나가 정상이라고 다른 하나의 답까지 자동 확정하지 않는다.

‘166을 실제 질문이라고 단정한 설명은 근거가 약하다’와 ‘전체 읽기 창의 정답은 반드시 PASS다’를 같은 명제로 취급하지 않는다. 종전 사용자 판단은 보존하고 전체 범위·평가 단위를 명확히 한 후 새 버전을 고정한다. 더 넓은 맥락을 근거로 임의로 정답을 경고로 바꾸지도 않는다.
