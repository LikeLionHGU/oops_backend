# 승인 정상 독려 대조 연결 — 2026-10-23

## 변경

`mimiminu-dev#audience-devaluation`의 기존 상품 안내 대조1개를 유지하고, 이미 PASS 승인·비교를 마친 `study-restart-encouragement`를 두 번째 정상 대조로 연결했다. 새 정답이나 공개 논란 사건을 추가한 것이 아니다.

연결한 대사는 다음3줄의 원문을 순서대로 공백으로 이은 것이다.

> 플래너에 계획을 적었는데 실천이 어려울 수도 있어요. 여러분들 공부가 계획만큼 안 됐다면, 하루 10분부터 다시 시작해 봅시다. 각자 속도에 맞춰 꾸준히 해보면 돼요.

실제 영상의 STT가 아닌 **사용자 승인 합성 개발 대조**다. 현재 청중을 지칭하고 공부 부족을 언급하더라도 낮추는 평가 없이 재시작을 돕는 대조를 함께 읽도록 했다. 원래 검토 대상의 해석·근거·검색 문구는 수정하지 않았다. 공용 판단 프롬프트·모델·검색 예산도 동일하다.

## provenance와 검증

context-unit의 해당 normalContrasts에 선택적 `approvalSource`를 추가했다. 경로는 `experiments/audience-boundary-draft-20261022/cases.json`, caseId는 `study-restart-encouragement`, 파일 SHA256은 `355890a7badb07387552fdfc58c6082b65b38cdda6d31c26a228c00e97a96848`다. 승인된 기존 기록은 수정하지 않았다.

빌더는 링크가 있으면 파일 해시·명시적 승인 상태·PASS·합성 출처·caseId 유일성·대사 완전 일치를 검사한다. 출처 변경·미승인·임의 수정이면 거절한다. 링크 파일도 build-manifest inputHashes에 포함해 변경을 추적한다. 링크 없는 기존 작성 대조를 새로 승인된 자료처럼 승격하지 않는다.

원장의 승인 메타데이터는 runtime 모델 참고로 내보내지 않는다. 모델에는 기존 방식의 ‘합성 개발 대조(실제 관측 아님)’ 문장만 추가된다. 전체 humanVerified=false·trainingUseAuthorized=false는 유지된다.
