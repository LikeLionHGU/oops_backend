## L3-1 구형 발언 경로 정리 — 2026-11-27~28

사용자의 **구형 경로와 전용 테스트 제거** 승인 범위에서 완료했다. 발언의 기본 후보 탐색→검증, OCR, 저장된 승인·실험 자료는 유지했다. 아래 11/24 이전 내용은 당시 이력이며 현재 상태는 이 절을 우선한다.

### 변경 범위

3. **데이터 물리 정리:** 먼저 역참조와 재생성 가능성을 확인하고 정확한 삭제 목록을 승인받는다. 완료 기준은 원장·전사·라벨·승인 연결이 보존되고 복구 경로가 확인되는 것이다. 이번에는 `.kiro/`와 데이터셋 모두 손대지 않았다.

**완료 판단: 이번 L3-1 범위는 okay.** 분석 품질을 바꾸는 실험과 유지보수 정리를 분리했고, 운영 분기를 줄이면서 현재 사례 추가·검색 검증을 유지했다. 전체 기술 부채 해소나 실제 영상 정확도 안정화까지 완료한 것은 아니다.

### 유지 결정

- `DialogueReadingPage.fits`는 페이지를 한 줄 늘릴 때마다 요청 JSON을 직렬화해 24,000코드포인트 상한을 확인한다. 페이지당 최대 128줄이라 비용이 작고, 정확한 상한 확인을 대체할 값싼 상한식이 없어 그대로 둔다.

### 검증
