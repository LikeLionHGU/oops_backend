## 범용화·출처 분리

원문/시간은 context-sources,짧은 해석·정상 경계는 context-units,상황·대상·평가·연결 검색 설명은 context-relations에 저장했다.6개 모두 동일 sourceGroupId `youtube-Duvb0IftlbI`로 같은 영상 출처를 보존한다. origin124 스냅샷과 사용자 승인 JSON을 각각 해시로 연결했다.

이번 원문은 **사용자 제공 스크립트**다. 새 sourceKind를 `USER_SUPPLIED_SCRIPT_NOT_AUDIO_VERIFIED`로 명시했다. 빌더는 해당 출처의 참고에만 사용자 스크립트·보충 설명·독립 검수 부재를 표시한다. 기존 STT/OCR 참고의 문구를 일괄 교체하지 않는다. 인명·단위·화자·혼인 상태를 추측 교정하지 않았다.

정자 수 대화와 동료 대화의 사용자 보충 설명은 검수 근거로 보존하되 새 입력의 실제 혼인·신원·관계로 복사하지 않도록 경계를 넣었다. 보충 정보가 없는 새 영상에도 동일 PASS를 강제하지 않는다. 당사자의 농담 여부와 별개로 시청자 관점의 평가도 원문에 근거해야 한다. 누군가 불쾌할 수 있다는 상상만으로 경고하지 않는다.

검토 대상2개에는 짧은 합성 정상 대조를 각각 연결했다. 이는 **개발자 초안·실제 관측 아님**이며 사용자가 합성 문장까지 따로 승인한 것은 아니다. 기존 경계를 새 원문의 근거로 대신 복사하지 않는다.
