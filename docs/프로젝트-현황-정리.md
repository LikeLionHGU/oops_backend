# 영상 논란 탐지 서비스 — 현재까지 만든 것

> 2026년 8월 11일 기준 · 비개발자용 정리

---

## 한 줄 요약

**영상을 올리면, 몇 분 몇 초에 어떤 논란거리가 있는지 목록으로 알려줍니다.**

지금 실제로 영상을 넣고 결과가 나오는 상태까지 왔습니다.

---

## 1. 무엇을 하는 서비스인가

유튜버가 영상을 올리기 전에, 나중에 논란이 될 만한 부분을 미리 찾아줍니다.

사람이 직접 검수하려면 영상을 처음부터 끝까지 봐야 하고, 봐도 놓치는 게 생깁니다.
이걸 AI가 대신 훑어서 **"03분 41초 이 부분, 이런 이유로 위험합니다"** 라고 짚어줍니다.

---

## 2. 어떻게 분석하는가

영상 하나가 들어오면 아래 순서로 처리됩니다. 전 과정이 자동입니다.

### 1단계 — 영상에서 재료를 뽑아냅니다

| 뽑는 것 | 방법 | 결과 |
|---|---|---|
| **말한 내용** | 음성 인식(AI) | "00:04에 '여기서 그러시면 안됩니다'라고 말함" |
| **화면에 나온 글자** | 이미지 문자 인식 | "00:02에 화면에 '재선거!!' 라고 적혀 있음" |

핵심은 **시간 정보가 같이 붙는다**는 점입니다. 그래야 "몇 분 몇 초"를 알려줄 수 있습니다.
화면 글자를 읽을 때는 그 순간의 화면 캡처 이미지도 함께 저장해 둡니다.

### 2단계 — 5가지 관점으로 훑습니다

같은 영상을 서로 다른 검사원 5명이 각자의 기준으로 보는 것과 같습니다.

| 검사원 | 무엇을 보나 | 예시 |
|---|---|---|
| **말 - 금지어 검사** | 발언 속 욕설·혐오 표현·개인정보 | "전화번호 010-1234-5678이 그대로 나옴" |
| **말 - 맥락 검사 (AI)** | 조롱, 비하, 과도한 일반화, 민감한 주제 | "'여자들은 원래' 라는 표현은 차별로 읽힐 수 있음" |
| **화면 - 금지어 검사** | 편집 자막 속 욕설·개인정보 | 자막에만 있고 말로는 안 한 문제 표현 |
| **화면 - 맥락 검사 (AI)** | 편집 자막의 민감한 내용 | "자막에 정치 이슈가 언급됨" |
| **말 ↔ 화면 대조 (AI)** | 실제 발언과 자막이 다른 경우 | "말은 순하게 했는데 자막은 자극적으로 바꿔 놓음" |

**금지어 검사와 맥락 검사를 왜 나눴나?**

욕설이나 전화번호는 목록으로 정리할 수 있어서 기계적으로 잡으면 됩니다. 빠르고 공짜입니다.
반면 "이게 조롱인지 친근한 농담인지"는 앞뒤 맥락을 봐야 알 수 있어서 AI 판단이 필요합니다.
둘을 겹쳐 놓으면, AI가 잠시 안 되더라도 확실한 것들은 계속 잡힙니다.

### 3단계 — 지금 시점에 괜찮은 얘기인지 확인합니다

이게 다른 서비스와 구별되는 부분입니다.

"재선거"라는 말 자체는 아무 문제가 없습니다.
그런데 **마침 재선거가 진행 중인 시기**라면 같은 영상이라도 반응이 완전히 달라집니다.

AI는 학습이 끝난 시점 이후의 뉴스를 모르기 때문에, 혼자서는 이 판단을 못 합니다.
그래서 이렇게 처리합니다.

```
영상에서 시사적인 주제를 뽑아낸다        →  "재선거"
              ↓
그 주제로 최근 한 달 뉴스를 검색한다      →  관련 기사 8건
              ↓
오늘 날짜 + 기사 목록을 AI에게 준다       →  "지금 올리면 위험한가?"
              ↓
판정                                    →  "선거 기간 중이라 논란 소지 있음"
```

뉴스 검색은 **별도 비용이나 가입 없이** 동작합니다.

### 4단계 — 중복을 정리하고 순서를 매깁니다

검사원 5명이 각자 보고하면 같은 장면이 여러 번 올라옵니다.
예를 들어 03:41의 문제 발언은 금지어 검사와 맥락 검사가 각각 보고하고,
그 표현이 화면 자막에도 있으면 화면 검사까지 세 번 보고합니다.

그대로 두면 똑같은 카드가 세 장 쌓입니다. 그래서 정리합니다.

1. **같은 장면인지 판단** — 3초 이내에 있고 같은 종류면 한 건으로 묶습니다
2. **대표 하나만 남김** — 가장 확실한 보고 하나만 남기고 나머지는 버립니다
3. **교차 확인은 가산점** — 말과 화면 **양쪽에서** 잡힌 건은 근거가 강하므로 점수를 올립니다
4. **순서 매기기** — 확신도, 위험 종류, 교차 확인 여부를 합쳐 우선순위를 계산합니다

그래서 **결과 목록의 맨 위가 "가장 먼저 확인해야 할 부분"** 이 됩니다.

## 3. 결과가 어떻게 나오는가

영상 하나당 이런 형태로 나옵니다.

```
심각도 요약:  높음 1건 / 중간 0건 / 낮음 0건

#1  00:02  [화면 자막]  심각도 높음
    실제 발언: "그래도 하나씩 처리해보려는데요"
    화면 자막: "재선거!!! 재선거!! 선생님 재선거 되세요"
    사유: 발언과 관련 없는 내용이 자막에 추가되어 의미가 왜곡되었습니다.
    화면 캡처: (이미지 링크)
```

각 항목에 담기는 정보:

- **시각** — 몇 분 몇 초부터 몇 초까지
- **종류** — 발언 문제인지 화면 자막 문제인지
- **심각도** — 높음 / 중간 / 낮음
- **근거** — 실제로 무슨 말을 했고 화면엔 뭐가 적혀 있었는지
- **사유** — 왜 문제가 되는지 설명
- **화면 캡처** — 그 순간의 영상 화면 이미지

시각 정보가 있어서, 화면에서 카드를 누르면 **영상의 그 지점으로 바로 이동**할 수 있습니다.

## 5. 아직 안 된 것

### 원래 계획에 있었지만 미룬 것

| 항목 | 설명 |
|---|---|
| **유튜브 댓글 분석** | 자리만 만들어 뒀고 내용은 비어 있습니다 |
| **포즈 / 제스처 판별** | 마찬가지로 자리만 있습니다 |

이 둘은 껍데기가 준비돼 있어서, 나중에 붙일 때 나머지 구조를 건드릴 필요가 없습니다.

### 품질 측면에서 더 다듬을 것

**1. 화면 글자 인식 정확도**

한글 자막에 테두리·그림자 효과가 들어가면 글자가 자주 깨집니다.
예: `재선거` → `재선커`, `재신거`, `쿄공운 재선거`

해상도를 높여 개선했지만 완전하지는 않습니다.
지금은 AI가 문맥으로 복원하도록 해서 보완하고 있습니다.

**2. 금지어 사전 보강**

욕설·혐오 표현 목록이 아직 얇습니다. 팀에서 계속 채워 넣어야 합니다.
파일 한 곳만 고치면 되고 개발 지식이 거의 필요 없습니다.

**3. 긴 영상 대응**

현재 30분까지만 처리합니다. 그 이상은 시간과 비용이 급격히 늘어납니다.

**4. 오탐 조절**

민감 주제를 넓게 잡도록 설정해 놨습니다. 놓치는 것보다 낫다고 판단해서인데,
실제로 써 보면서 기준을 조일지 결정해야 합니다.

## 7. 서버 구성

프로그램이 두 개로 나뉘어 있습니다. **서버는 한 대면 됩니다.**

| 프로그램 | 역할 |
|---|---|
| **메인 서버** | 화면(프론트)과 대화, 분석 순서 관리, 결과 저장 |
| **분석 전용 서버** | 음성 인식과 화면 글자 인식 |

음성 인식과 이미지 인식 기술이 다른 언어로 돼 있어서 분리했습니다.
같은 컴퓨터 안에서 서로 통신하므로 도메인도 하나면 충분합니다.

다만 화면 글자 인식이 컴퓨터 자원을 꽤 씁니다.
서버를 빌릴 때 **최소 사양(메모리 1GB)으로는 안 돌아갑니다.** 4GB 이상을 권합니다.
