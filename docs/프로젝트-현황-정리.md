# OOPS — 공개 전 영상 검수 도우미

> 2026년 8월 12일 기준 · 비개발자용 정리

---

## 한 줄 요약

**편집본 전체를 다시 보는 대신, 다시 확인할 구간만 보세요.**

원본 발언과 편집 자막, 외부 맥락을 비교해 공개 전에 확인할 지점을 시각과 함께 짚어줍니다.

**AI가 삭제 여부를 결정하지 않습니다. 확인할 근거를 제공합니다.**

---

## 1. 왜 방향을 바꿨나

처음 가설은 이랬습니다.

> 제작자가 영상 속 논란 요소를 놓친다 → AI가 찾아준다 → 업로드 전에 수정한다

현업 인터뷰를 하면서 이 가설이 절반만 맞다는 걸 알게 됐습니다.

**PD와 편집자는 영상을 수십 번 반복해서 봅니다.** 눈에 띄는 문제는 이미 알고 있고,
알면서 일부러 넣은 장면도 있습니다.
"13분 20초에 이런 농담이 있습니다" 같은 알림은 새로운 가치가 없습니다.
"나도 알아, 그래서 넣은 건데"로 끝납니다.

**AI가 도덕 판단을 대신하는 구조도 약합니다.**
"이 발언은 부적절합니다", "논란 가능성 85%" 같은 출력은 제작자의 판단과 충돌합니다.

그래서 문제 정의를 바꿨습니다.

| | |
|---|---|
| **전** | AI가 논란이 될 영상을 찾아준다 |
| **후** | 제작팀이 놓칠 수 있는 **검수 사각지대**를 찾아, 다시 확인할 구간과 근거를 준다 |

---

## 2. 어떤 사각지대를 찾나

반복해서 영상을 만들다 보면 이런 것들이 남습니다.

1. **익숙해져서 무뎌진다** — 너무 많이 봐서 지나친다
2. **본인이 모르는 맥락이 있다** — 특정 커뮤니티에서 다른 뜻으로 쓰이는 표현
3. **편집자가 의도와 다르게 표현한다** — 출연자는 A라고 했는데 자막은 B
4. **세부에서 오류가 난다** — 이름, 날짜, 숫자

여기만 찾습니다.

---

## 3. 누구를 위한 것인가

**편집을 다른 사람에게 맡기는, 20분 이상 토크·인터뷰 채널.**

- 본인이 직접 출연하고 편집자가 따로 있음
- 20~60분 분량을 주기적으로 업로드
- 2인 이상 대화, 즉흥 발언이 많음
- 다른 사람·회사·사건을 자주 언급
- 방송사 수준의 검수 팀은 없음

경제·정책·투자 채널은 뺐습니다. 대본 기반이라 대본만 검토해도 대부분 해결되고,
영상 단위로 볼 이유가 약했습니다.

## 4. 어떻게 분석하나

### 1단계 — 영상에서 재료를 뽑습니다

| 뽑는 것 | 방법 |
|---|---|
| **말한 내용** | 음성 인식 (시각 정보 포함) |
| **화면에 나온 글자** | 이미지 문자 인식 (그 순간 화면 캡처도 함께) |

**여기서 채널 로고를 걸러냅니다.** 화면 구석에 늘 떠 있는 로고가
자막으로 섞여 들어가는 문제가 있었습니다.
같은 자리에 계속 나오면서 내용도 매번 같으면 로고로 보고 뺍니다.

### 2단계 — 발언과 자막을 각각 훑습니다

**서로 비교하지 않습니다.** 각자 자기 내용만 봅니다.

| 보는 것 | 예 |
|---|---|
| 금지어·개인정보 | 전화번호가 그대로 나옴 |
| 낯선 커뮤니티 표현 | 특정 커뮤니티 말투로 알려진 어미 |
| 특정 대상 평가 | 소개 중인 가게를 깎아내리는 대목 |
| 이름·날짜·숫자 | 실제 기사와 어긋나는 서술 |
| 최근 이슈와 얽힌 주제 | 지금 진행 중인 사건 |

### 3단계 — 겹치는 것을 하나로 묶습니다

같은 것을 두고 분석기마다 다르게 보고합니다.
"패스트푸드"를 한쪽은 비하로, 다른 쪽은 일반화로 잡는 식입니다.
사용자에게는 같은 지적이므로 카드 하나로 합칩니다.

여러 번 나온 건 **어디어디에 나왔는지** 함께 보여줍니다.

```
(등장: 00:26, 00:35, 00:44)
```

## 5. 결과가 어떻게 나오나

```
01:08   확인 필요
발언: "너무 특색이 없어가지고"
확인 이유: 소개 중인 가게의 메뉴를 평가하는 대목입니다. 당사자가 볼 수 있습니다.
(등장: 01:08, 01:10)

──────────────────────────────
최종 수정 여부는 제작자가 판단하시면 됩니다.
```

**확률 점수나 "부적절합니다" 같은 판정은 내지 않습니다.**
안내 문구도 항목마다 반복하지 않고 맨 아래 한 번만 나옵니다.

---

## 6. 특히 신경 쓴 것

### 모르는 맥락을 알려주는 것

편집자가 모든 사회적 이슈를 알기는 어렵습니다.
특정 커뮤니티에서만 다른 뜻으로 쓰이는 표현이 대표적입니다.

여기서 우리가 하는 일은 **"이건 나쁜 표현입니다"가 아니라
"이 표현은 이런 맥락에서 논의된 적이 있습니다"** 입니다.

사전과 AI 양쪽으로 봅니다. AI만으로는 사투리나 일상 표현과 겹치는 것을
애매하다고 그냥 넘어가기 때문입니다.

### 잘못 잡는 것을 조심하는 것

"틀렸다"고 했는데 틀리지 않았으면 제작자가 도구 자체를 안 믿게 됩니다.
그래서 사실 확인은 애매하면 통과시키도록 했습니다.

알맹이 없는 설명도 버립니다.
"특정한 맥락에서 사용될 수 있는 표현입니다" 같은 문장은
형식만 갖췄을 뿐 확인할 방법이 없어서 없느니만 못합니다.

## 9. 남은 일

### 배포 (가장 큼)

지금은 택민님 컴퓨터에서만 돌아갑니다. 프론트가 붙으려면 서버가 필요합니다.

- 권장 사양: 2 vCPU / 4GB RAM 이상
- 서버는 한 대, 도메인도 하나면 충분합니다

### 품질

- **커뮤니티 은어 사전 채우기** — 개발 지식 없이 한 줄씩 추가할 수 있습니다.
  팀에서 나눠 하면 품질이 크게 올라갑니다
- 테스트 영상 늘리기 — 지금 몇 개로는 오탐·미탐 감이 안 잡힙니다
- 화면 글자 인식 정확도

### 운영

- 인증이 없습니다. 주소가 공개되면 누구나 영상을 올릴 수 있습니다
- AI 사용량 한도 — 계정 등급이 낮으면 분석이 중간에 멈춥니다
