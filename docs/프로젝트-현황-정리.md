# OOPS — 공개 전 영상 검수 도우미

> 2026년 8월 12일 기준 · 비개발자용 정리

---

## 한 줄 요약

**편집본 전체를 다시 보는 대신, 다시 확인할 구간만 보세요.**

원본 발언과 편집 자막, 외부 맥락을 비교해 공개 전에 확인할 지점을 시각과 함께 짚어줍니다.

**AI가 삭제 여부를 결정하지 않습니다. 확인할 근거를 제공합니다.**

---

## 1. 왜 방향을 바꿨나

처음 가설은 이랬습니다.

> 제작자가 영상 속 논란 요소를 놓친다 → AI가 찾아준다 → 업로드 전에 수정한다

현업 인터뷰를 하면서 이 가설이 절반만 맞다는 걸 알게 됐습니다.

**PD와 편집자는 영상을 수십 번 반복해서 봅니다.** 눈에 띄는 문제는 이미 알고 있고,
알면서 일부러 넣은 장면도 있습니다.
"13분 20초에 이런 농담이 있습니다" 같은 알림은 새로운 가치가 없습니다.
"나도 알아, 그래서 넣은 건데"로 끝납니다.

**AI가 도덕 판단을 대신하는 구조도 약합니다.**
"이 발언은 부적절합니다", "논란 가능성 85%" 같은 출력은 제작자의 판단과 충돌합니다.

그래서 문제 정의를 바꿨습니다.

| | |
|---|---|
| **전** | AI가 논란이 될 영상을 찾아준다 |
| **후** | 제작팀이 놓칠 수 있는 **검수 사각지대**를 찾아, 다시 확인할 구간과 근거를 준다 |

---

## 2. 어떤 사각지대를 찾나

반복해서 영상을 만들다 보면 이런 것들이 남습니다.

1. **익숙해져서 무뎌진다** — 너무 많이 봐서 지나친다
2. **본인이 모르는 맥락이 있다** — 특정 커뮤니티에서 다른 뜻으로 쓰이는 표현
3. **편집자가 의도와 다르게 표현한다** — 출연자는 A라고 했는데 자막은 B
4. **세부에서 오류가 난다** — 이름, 날짜, 숫자

여기만 찾습니다.

---

## 3. 누구를 위한 것인가

**편집을 다른 사람에게 맡기는, 20분 이상 토크·인터뷰 채널.**

- 본인이 직접 출연하고 편집자가 따로 있음
- 20~60분 분량을 주기적으로 업로드
- 2인 이상 대화, 즉흥 발언이 많음
- 다른 사람·회사·사건을 자주 언급
- 방송사 수준의 검수 팀은 없음

경제·정책·투자 채널은 뺐습니다. 대본 기반이라 대본만 검토해도 대부분 해결되고,
영상 단위로 볼 이유가 약했습니다.

## 4. 어떻게 분석하나

### 1단계 — 영상에서 재료를 뽑습니다

| 뽑는 것 | 방법 |
|---|---|
| **말한 내용** | 음성 인식 (시각 정보 포함) |
| **화면에 나온 글자** | 이미지 문자 인식 (그 순간 화면 캡처도 함께) |

**여기서 채널 로고를 걸러냅니다.** 화면 구석에 늘 떠 있는 로고가
자막으로 섞여 들어가는 문제가 있었습니다.
같은 자리에 계속 나오면서 내용도 매번 같으면 로고로 보고 뺍니다.

### 2단계 — 발언과 자막을 각각 훑습니다

**서로 비교하지 않습니다.** 각자 자기 내용만 봅니다.

| 보는 것 | 예 |
|---|---|
| 금지어·개인정보 | 전화번호가 그대로 나옴 |
| 낯선 커뮤니티 표현 | 특정 커뮤니티 말투로 알려진 어미 |
| 특정 대상 평가 | 소개 중인 가게를 깎아내리는 대목 |
| 이름·날짜·숫자 | 실제 기사와 어긋나는 서술 |
| 최근 이슈와 얽힌 주제 | 지금 진행 중인 사건 |

### 3단계 — 겹치는 것을 하나로 묶습니다

같은 것을 두고 분석기마다 다르게 보고합니다.
"패스트푸드"를 한쪽은 비하로, 다른 쪽은 일반화로 잡는 식입니다.
사용자에게는 같은 지적이므로 카드 하나로 합칩니다.

여러 번 나온 건 **어디어디에 나왔는지** 함께 보여줍니다.

```
(등장: 00:26, 00:35, 00:44)
```

## 5. 결과가 어떻게 나오나

```
01:08   확인 필요
발언: "너무 특색이 없어가지고"
확인 이유: 소개 중인 가게의 메뉴를 평가하는 대목입니다. 당사자가 볼 수 있습니다.
(등장: 01:08, 01:10)

──────────────────────────────
최종 수정 여부는 제작자가 판단하시면 됩니다.
```

**확률 점수나 "부적절합니다" 같은 판정은 내지 않습니다.**
안내 문구도 항목마다 반복하지 않고 맨 아래 한 번만 나옵니다.

## 6. 특히 신경 쓴 것

### 모르는 맥락을 알려주는 것

편집자가 모든 사회적 이슈를 알기는 어렵습니다.
특정 커뮤니티에서만 다른 뜻으로 쓰이는 표현이 대표적입니다.

여기서 우리가 하는 일은 **"이건 나쁜 표현입니다"가 아니라
"이 표현은 이런 맥락에서 논의된 적이 있습니다"** 입니다.

사전과 AI 양쪽으로 봅니다. AI만으로는 사투리나 일상 표현과 겹치는 것을
애매하다고 그냥 넘어가기 때문입니다.

### 근거를 같이 주는 것

이름이나 날짜를 확인할 때, 그리고 최근 배경을 알려줄 때는
**AI가 실제로 본 기사를 카드에 같이 붙입니다.**

```
확인 이유: 영상에서는 2019년이라고 했는데 기사에는 2020년으로 나옵니다.

AI가 확인한 자료 2건 — 직접 열어서 확인하세요
· OO그룹 창립 20주년...2020년 설립 후 성장세   한국경제 · 8월 3일
· OO그룹, 설립 6년 만에 매출 1조                 매일경제 · 7월 28일
```

전에는 기사를 검색해서 AI에게 넣고 그냥 버렸습니다.
사용자에게는 "기사에는 2020년으로 나옵니다"라는 문장 하나만 갔습니다.

이 도구는 잘못 잡는 일이 반드시 있습니다.
"여기 롯데리아 없나?"를 "롯데리아 싱가포르 2호점 오픈" 기사와 대조한 적이 있습니다.
링크가 있었다면 30초 만에 무관한 기사라고 넘겼을 겁니다.
없으면 판단할 방법이 없어서 도구 전체를 의심하게 됩니다.

**우리가 하는 일은 판단이 아니라 근거를 주는 것**이라는 원칙과도 맞습니다.
근거를 확인할 수 없으면 결국 AI 말을 믿으라는 것과 같습니다.

### 잘못 잡는 것을 조심하는 것

"틀렸다"고 했는데 틀리지 않았으면 제작자가 도구 자체를 안 믿게 됩니다.
그래서 사실 확인은 애매하면 통과시키도록 했습니다.

알맹이 없는 설명도 버립니다.
"특정한 맥락에서 사용될 수 있는 표현입니다" 같은 문장은
형식만 갖췄을 뿐 확인할 방법이 없어서 없느니만 못합니다.

## 7-1. 영상 길이

**90분까지** 받습니다.

화면 인식은 영상이 길어도 **2~3분 안에 끝납니다.**
길이에 비례해 프레임을 늘리면 60분 영상에 900장이 되어 감당이 안 되므로,
장수를 고정하고 간격을 늘립니다. 자막은 몇 초씩 유지되니 대부분 잡힙니다.

다만 **긴 영상은 비용이 큽니다.** 60분이면 약 550원이고,
그중 500원이 음성 인식입니다.
시연은 3~5분짜리를 권합니다.

## 7-2. 실패하면 실패라고 말합니다

음성도 화면 글자도 못 읽으면 분석을 **실패**로 끝냅니다.

그냥 넘어가면 "확인할 지점 없음" 으로 끝나는데,
이건 "검수했더니 괜찮다" 가 아니라 "아무것도 못 봤다" 입니다.
둘을 헷갈리게 하면 안 됩니다.

| **유튜브 댓글 분석** | 공개 전에는 그 영상에 댓글이 없습니다 |
| **포즈·제스처 판별** | 범위에서 뺐습니다 |
| **화면 글자의 이름·날짜·수치 확인** | 발언 쪽은 켰지만 화면 쪽은 껐습니다. 메뉴판의 "김치찌개 8000원" 을 "평균 가격" 기사와 대조해 틀렸다고 올리는 오탐이 반복됐습니다. 가게마다 값이 다른 게 당연한데요. 메뉴판은 이제 코드에서 걸러내지만 간판·영수증은 아직 못 가립니다 |

앞의 셋은 코드가 남아 있어서 설정 한 줄로 다시 켤 수 있습니다.

> **오탐 한 건이 목록 전체의 신뢰를 깎습니다.** 열어봤는데 고칠 것이 없으면
> 제작자는 나머지 카드도 같은 수준이라고 봅니다. 그래서 확인이 안 된 기능은
> 켜두기보다 끄는 쪽을 택했습니다.

## 9. 남은 일

### 품질 확인 (가장 큼)

배포는 끝났습니다. 커스텀 도메인 + Vercel 프론트로 붙어 있습니다.
남은 것은 **실제 영상으로 오탐·미탐을 재는 일**입니다.

- 테스트 영상이 몇 개뿐입니다. 5~10개는 돌려봐야 감이 잡힙니다
- 끄고 켠 기능(사실 확인, 발언↔자막 비교)의 판단 근거가 영상 두세 편입니다

### 품질

- **커뮤니티 은어 사전 채우기** — 개발 지식 없이 한 줄씩 추가할 수 있습니다.
  팀에서 나눠 하면 품질이 크게 올라갑니다
- 테스트 영상 늘리기 — 지금 몇 개로는 오탐·미탐 감이 안 잡힙니다
- 화면 글자 인식 정확도

### 운영

- 인증이 없습니다. 주소가 공개되면 누구나 영상을 올릴 수 있습니다
- AI 사용량 한도 — 계정 등급이 낮으면 분석이 중간에 멈춥니다

## 10. 비용

영상 1분당 **약 10원** 수준입니다. 60분이면 550원 안팎입니다.

| 항목 | 단가 |
|---|---|
| 음성 인식 | 분당 약 8원 — **비용의 90%** |
| AI 판단 | 영상당 40~60원 |
| 화면 글자 인식 | 무료 (로컬에서 돕니다) |
| 뉴스 검색 | 무료 |

**짧은 영상은 1분당 단가가 더 높게 나옵니다.** 대본 길이와 무관한 고정 호출이
있어서, 1분짜리는 1분당 40~50원이 나오기도 합니다.

같은 영상을 반복 테스트하면 그만큼 쌓이니, 개발 중에는 짧은 영상을 쓰는 게 좋습니다.
