## 서비스 실행 전 고정하는 검토 초안

원음·표정·억양·전체 프레임은 직접 검수하지 않았다. 다음은 자동 자막 기반 개발 초안이며 사용자 승인 정답이 아니다. 제목·댓글·이미 알려진 논란을 정답 근거로 쓰지 않는다.

1. **언어 대화:** 외국어를 능숙하게 보이는 방법과 회사 경험을 농담으로 풀어가는 흐름이다. 국적/언어의 등장 자체는 경고 근거가 아니다. 취업 능력 과장 권유로 읽힐 지점은 있으나 실제 사기나 위험 행동 권유를 확정하지 않는다. 자막의 부정확한 폭력처럼 보이는 문자열은 원음 확인 없이 실제 폭력 발언으로 고치거나 판정하지 않는다. PASS/확인 필요 경계 관찰 대상이다.
2. **체중 감량:** 출연자가 자신의 과거 체중과 입시 과정에서 만든 식단·운동 루틴을 설명한다. 자기 경험을 타인 비하로 바꾸지 않는다. 마지막 음식 맛 반응은 일반 취향 평가 가능성을 먼저 대조한다. 텍스트상 구체적 외모 공격은 보이지 않는 PASS 초안. 감량법의 의학적 안전성이나 섭식 문제까지 현재 자료로 확정하지 않는다.
3. **학원 회고:** 낮은 반 학생을 무시하는 발언을 과거 들었던 말로 소개하고 자신이 받은 충격·결심을 설명한다. 인용 내용에 모욕이 있다고 현재 화자가 하위권 학생을 공격했다고 판정하면 역할 오해다. 다만 인용 형식만으로 내용 자체의 독립적인 검토 이유를 지우지도 않는다. 회고/비판 전달과 독립 문제를 분리할 후보이며 사용자 판단 전 PASS/검토 정답을 확정하지 않는다.
4. **성적 대화:** 본인의 진학 선택을 성적과 연결해 설명하다 상대의 여러 번 입시 경험을 언급한다. 자기 설명은 정상 대조, 상대 능력을 낮추는 독립 표현인지 여부는 원문 연결로 검토한다. 명확한 거절/강요가 확인된 영상은 아니므로 원래 제안한 거절 대화 조건을 완전히 충족한다고 표시하지 않는다. 제목의 일진을 실제 학교폭력 증거로 쓰지 않는다.
5. **플래너 소개:** 구성품·활용·판매 정보가 중심이다. 자기 얼굴 묘사를 타인 외모 비하로, 공부 독려를 특정 집단 폄하로, 상품 가격을 자동 사실대조로 확대하지 않는다. 텍스트상 대체로 정상 상품 소개 초안이며 약10분 동안의 후보 예산·문맥 제한도 확인한다. 영상 전체 안전/광고 적법성/가격 사실을 보증하지 않는다.

## 실행 계약

- 다섯 링크를 각1회만 서비스 분석한다. 새 예산·음성 Groq 및 텍스트/필요 프레임 OpenAI 전송 승인이 필요하다. 과거 예산/전송 승인을 재사용하지 않는다.
- 현재 유튜브 링크는 STT/OCR이 되지만 시각 후보 검증은 `VISUAL_UPLOAD_ONLY`로 실패할 수 있다. 이를 PASS나 미탐 확정으로 집계하지 않는다.
- 개정45 실행 여부, 처리 시간, 후보·PASS·검증 실패·시각 의존성·실제 선택 사전 사례·최종 카드·OCR 제외 경고를 비교한다.
- 카드0을 정상 보증으로 해석하지 않는다. 카드 수보다 발언 역할·근거 연결을 검토한다. 의미 오류와 출력 계약 오류를 구분한다.
- 모든 결과를 먼저 모은 뒤 공통 실패를 정리하며, 영상마다 프롬프트를 바꾸거나 사전 사례를 자동 승격하지 않는다. 사용자 승인 항목만 평가 정답으로 기록한다.
