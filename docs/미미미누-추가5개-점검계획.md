## 서비스 실행 전 고정하는 검토 초안

2. **체중 감량:** 출연자가 자신의 과거 체중과 입시 과정에서 만든 식단·운동 루틴을 설명한다. 자기 경험을 타인 비하로 바꾸지 않는다. 마지막 음식 맛 반응은 일반 취향 평가 가능성을 먼저 대조한다. 텍스트상 구체적 외모 공격은 보이지 않는 PASS 초안. 감량법의 의학적 안전성이나 섭식 문제까지 현재 자료로 확정하지 않는다.

4. **성적 대화:** 본인의 진학 선택을 성적과 연결해 설명하다 상대의 여러 번 입시 경험을 언급한다. 자기 설명은 정상 대조, 상대 능력을 낮추는 독립 표현인지 여부는 원문 연결로 검토한다. 명확한 거절/강요가 확인된 영상은 아니므로 원래 제안한 거절 대화 조건을 완전히 충족한다고 표시하지 않는다. 제목의 일진을 실제 학교폭력 증거로 쓰지 않는다.

다음 수정 설계는 원문을 추측 복원하거나 서버가 이웃 문구로 대표를 조용히 바꾸는 방식이 아니어야 한다. 필수 대표 문구가 불명확한 판단은 미확인으로 보존하고, 실제 읽히는 다른 문구에 독립적 근거가 있으면 그 문구를 별도 검토해야 한다. 모든 REVIEW의 missingInformation을 금지하거나 모든 저신뢰 OCR을 버리는 식으로 확대하지 않는다.
