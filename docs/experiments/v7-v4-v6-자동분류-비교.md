1. 현재 발견·검증 응답을 고정 fixture로 삼아, 성적 소재 언급과 성적 모욕/대상화의 경계·비판적 인용과 화자 자신의 공격을 사람이 검수한다. 새 유료 호출 전에 경계 회귀 테스트부터 만든다.
2. `PASS`, 검증 계약 실패, 시각 미설정, 후보 상한 미평가를 분리해 추적한다. 실패를 없애기 위해 근거 검증을 느슨하게 하지 않는다.
3. 동일 대상·쟁점·근거의 중복 후보를 추적한다. 최종 fusion까지 검증하지 않았으므로 UI 카드 중복 해결로 완료 처리하지 않는다.
4. 이번 소재에 맞는 새 사례/검색 키가 실제 필요하다면 검수된 정상 대조와 함께 확장한다. 현재3키를 무조건 반환하게 하거나 참고 수 상한부터 늘리지 않는다.
