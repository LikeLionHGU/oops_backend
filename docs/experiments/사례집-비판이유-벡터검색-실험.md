# 사례집 비판 이유 벡터 검색 실험

설계: [2026-11-07-casebook-reason-vector-design.md](../superpowers/specs/2026-11-07-casebook-reason-vector-design.md). 계획: [2026-11-07-casebook-reason-vector.md](../superpowers/plans/2026-11-07-casebook-reason-vector.md). 동결 규칙: [casebook-vector-v1.json](retrieval-rules/casebook-vector-v1.json).

실험 데이터는 `datasets/controversy/experiments/casebook-vector-20261107/`(gitignore)에 둔다. 아래에서 `$C`는 이 경로, `$P`는 `/opt/anaconda3/envs/oops-analysis/bin/python`이다. 유료 단계는 사용자가 직접 실행한다.

## 조건 정의(구현 후 확정)

- 조건마다 참고 사례 선택 방식이 발견과 검증 두 단계 모두에 적용된다. NONE은 두 단계 모두 참고 없음, KEYWORD는 두 단계 모두 키워드 선택(검증은 후보 인용으로 다시 고름), VECTOR는 발견 단계에서 고른 벡터 참고가 검증까지 그대로 간다. 그래서 결과 차이는 "발견 단계 참고만의 효과"가 아니라 "참고 선택 방식 전체의 효과"다.
- KEYWORD와 VECTOR 모두 대상의 사건 family 예시를 제외한다. VECTOR는 `familiesPath`가 필수이고, 같은 family ID가 선택 파일에 있으면 `prepare`가 실패한다.
- 찾기 지표는 두 방식 모두 실제로 발견 요청에 붙은 참고(repeat 0의 `discoveryReferenceIds`, 앞 3개)로 센다. 키워드는 runtime의 모든 SPEECH 예시를 고를 수 있으므로 그 전체를 기준으로 적중과 우연 기준선을 계산하고, 분모는 두 방식 모두 사례집 문서 기준으로 같게 둔다.

## 실행 순서

1. 평가 입력(무료):
   `python3 tools/casebook_reasons.py items datasets/controversy/guidelines/runtime.json datasets/controversy/incidents $C/items-v1`
   추출한 인용을 채팅에서 확인한다. 발언이 아닌 인용(프로그램명, 사과문 문장 등)은 `$C/quote-overrides.json`(`{"statementId": ["인용", ...]}`, `[]`는 제외)으로 고치고 새 폴더로 다시 만든다.
2. 사례집 비판 이유 초안(유료):
   `$P tools/casebook_reasons.py draft $C/items-v2/casebook-items-v1.json $C/reasons-draft --instructions docs/experiments/label-instructions/Casebook-reason-v1.md`
   → `python3 tools/casebook_reasons.py show ... $C/reasons-cards.md` → 채팅 확인 → `finalize ... $C/casebook-reasons-v1.json`.
3. 세 조건 spec 작성(Claude, 무료). 대상 = 사례집 인용 세그먼트 전체 + J1 무작위 층 PASS 58개, 선택기 A0. `NONE`, `KEYWORD` plan을 `prepare`한다.
4. 대상 비판 이유(유료): `$P tools/query_reasons.py $C/main-none-plan/plan.json $C/query-reasons --instructions docs/experiments/label-instructions/Query-reason-v1.md --max-calls <대상 수>`
5. 벡터 선택(무료): `$P tools/reason_vectors.py select $C/items-v2/casebook-items-v1.json $C/casebook-reasons-v1.json $C/items-v2/families.json $C/query-reasons/query-reasons.json $C/vectors --revision 5617a9f61b028005a4858fdac845db406aefb181` → `VECTOR` plan `prepare`.
6. 비용 probe(사례집 영상 하나, 대상 5개, 세 조건) 후 본 실행(유료, `contextExperiment` 작업, J1과 같은 동의 토큰 절차).
7. 지표(무료): `python3 tools/reason_vectors.py retrieval $C/items-v2/casebook-items-v1.json $C/items-v2/families.json $C/items-v2/targets.json $C/query-reasons/query-reasons.json datasets/controversy/guidelines/runtime.json $C/vectors/vector-selections-v1.json <VECTOR run>/results.jsonl <KEYWORD run>/results.jsonl $C/retrieval-v1.json`, `python3 tools/casebook_vector_eval.py $C/items-v2 datasets/controversy/experiments/j1-baseline-20261107 $C/eval-v1.json --run NONE=... --run KEYWORD=... --run VECTOR=...`
