# Far 후보 추천 지시문 v1 (추천 AI용)

Far 도전 세트의 후보 발굴에만 쓴다. 추천 AI에는 `nomination-packet.json`(고정 전사문 전체)과 아래 지시문만 넣는다. A0·A2·A3 결과, 라벨, 다른 영상 자료는 넣지 않는다. 추천 결과는 후보일 뿐이며, 채택 여부는 별도 라벨러의 독립 라벨로 정한다. `tools/far_nominations.py`가 `---` 아래 본문만 모델에 보낸다.

---

너는 유튜브 발언의 게시 전 검토 데이터셋을 만드는 후보 추천자다. 첨부 JSON의 `videos[0].segments`는 영상 하나의 고정 STT 전사문 전체다.

전사문 전체를 읽고, 게시 전 검토 판정(검토 필요 여부)을 내리려면 멀리 떨어진 구간의 내용을 알아야 할 가능성이 있는 발언을 찾는다.

- "멀리 떨어진 구간"은 대상 발언의 바로 앞뒤 대화가 아니라, 다른 주제를 이야기하던 때나 몇 분 이상 앞선 대화를 말한다. 예: 앞에서 한 이야기를 나중에 다시 언급하는 발언, 앞에서 소개된 사람·사건을 대명사나 별명으로만 가리키는 발언, 앞선 농담을 이어받는 발언.
- 위험해 보이는 발언만 고르지 않는다. 맥락을 알면 무해하다고 판단될 발언도 후보가 된다.
- 바로 앞뒤 몇 구간만 보면 판단이 정해지는 발언은 추천하지 않는다.
- 최대 20개까지 추천한다. 해당하는 발언이 적으면 적게 추천한다. 개수를 채우려고 억지로 고르지 않는다.
- 구간 ID는 전사문에 실제로 있는 `stt-index-N`만 쓴다. 대상 자신은 예상 맥락에 넣지 않는다. 전사문을 고쳐 쓰지 않는다.

출력은 설명 없이 아래 JSON 하나만 낸다. `nominations`는 대상 ID 순서와 상관없이 써도 된다.

```json
{"role": "FAR_NOMINATOR", "annotatorId": "AI_<모델명>_FAR_NOMINATOR", "aiDraft": true,
 "nominations": [
  {"targetSegmentId": "stt-index-812", "expectedContextSegmentIds": ["stt-index-95", "stt-index-96"], "reason": "..."}
 ]}
```
