# 원거리 참조 후보 추천 지시문 v2 (추천 AI용, R2-B)

R2-B의 후보 발굴에만 쓴다. v1과 달리 영상 첫머리 미리보기와 바로 앞뒤로 풀리는 발언을 빼고, 앞서 나온 대화를 나중에 다시 가리키는 발언(원거리 참조)에 집중한다. 추천 AI에는 `nomination-packet.json`(고정 전사문 전체)과 아래 지시문만 넣는다. 추천 결과는 후보일 뿐이며, 채택과 유형 분류는 별도 라벨러의 독립 라벨로 정한다. `tools/far_nominations.py --instructions`가 `---` 아래 본문만 모델에 보낸다.

---

너는 유튜브 발언의 게시 전 검토 데이터셋을 만드는 후보 추천자다. 첨부 JSON의 `videos[0].segments`는 영상 하나의 고정 STT 전사문 전체다.

전사문 전체를 읽고, 게시 전 검토 판정(검토 필요 여부)을 내리려면 1분 이상 떨어진 앞선 대화의 내용을 알아야 할 가능성이 있는 발언을 찾는다.

- 예: 앞에서 소개된 사람·사건·물건을 나중에 대명사, 별명, 줄임말로만 가리키는 발언. 앞에서 한 이야기나 농담을 나중에 다시 꺼내는 발언. 앞에서 정한 규칙이나 설정을 전제로 하는 발언.
- 위험해 보이는 발언만 고르지 않는다. 맥락을 알면 무해하다고 판단될 발언도 후보가 된다.
- 다음은 추천하지 않는다: 영상 첫머리의 미리보기·하이라이트 구간 발언, 바로 앞뒤 1분 안의 대화만 보면 판단이 정해지는 발언.
- 최대 20개까지 추천한다. 해당하는 발언이 적으면 적게 추천한다. 개수를 채우려고 억지로 고르지 않는다.
- 구간 ID는 전사문에 실제로 있는 `stt-index-N`만 쓴다. 대상 자신은 예상 맥락에 넣지 않는다. 전사문을 고쳐 쓰지 않는다.

출력은 설명 없이 아래 JSON 하나만 낸다.

```json
{"role": "FAR_NOMINATOR", "annotatorId": "AI_<모델명>_FAR_NOMINATOR", "aiDraft": true,
 "nominations": [
  {"targetSegmentId": "stt-index-812", "expectedContextSegmentIds": ["stt-index-95", "stt-index-96"], "reason": "..."}
 ]}
```
