### 사례는 실제 들어갔는가?

실제 F2의 system 요청에는 공통 `local-life-devaluation` 패턴과 **pisik-C, pisik-B 두 예시가 모두 있었다**. current runtime.json의 context와 정확히 같은 내용임을 대조해 보관했다. B 예시가 사전에만 있고 요청에는 빠졌다는 가설은 이 입력에 해당하지 않는다.

현재 작업 사전은 SPEECH 기준 공통 패턴 7개/사용 가능한 예시 8개다(CAPTION 전용 1개는 제외). 로컬 검색은 문자 trigram이며 의미 검색/학습이 아니다. 실제 B 허용 창 35행·20.5~80.5초를 사용한 읽기 전용 Java audit에서, 당시 제안 인용 6개를 focus로 주면 C/B가 선택되고 예산 제외는 0이었다. 모든 제안 인용이 해당 저장 원문 전체와 같음을 확인했으므로 이 focus 시험에 한해 원문 일부 인용의 차이는 없다. anchor만 focus로 주면 B/C 순서였다. 이는 현재 라이브러리의 저장 창 검색 확인이지 모델 자동 탐색/전체 영상 재분석이 아니다.

검토 결론에는 부재나 대체 이상의 구체적 평가 연결이 있어야 한다. PASS에도 그 비판 해석이 왜 현재 근거로 성립하지 않는지 남긴다. 논란 댓글·기사 해석·과거 사건을 현재 영상의 근거처럼 넣지 않는다.

## 준비한 시험: 판단 문구는 유지, 선택 입력만 비교

`tools/context_boundary_packet.py`로 118의 실제 두 B 선택과 117의 N5/N6 선택을 보존한 오프라인 packet을 만들었다. 각 조건의 기존 선택/진단 선택을 같은 CLOSED_SCOPE 판단에 넣는 **8요청 미리보기**다. 아직 실행기·유료 예약 원장에 연결하지 않았고 실행 OFF다.

B 진단 선택은 실제 원문 ID로 다음 8조각을 지정했다. PRIMARY anchor는 `stt-2240` 그대로다.

| 역할 | 실제 원문 |
| --- | --- |
| PRIMARY | 이걸로 대신 먹는 거야 |
| TARGET | 여기 (`stt-2229`의 실제 부분 인용) |
| CONTEXT | 여기 뭐 있겠나? |
| CONTEXT | 롯데리아 같은 소리 하고 있어 지금 |
| CONTEXT | 여기가 롯데리아가 없다 그랬거든? |
| CONTEXT | 젊은 아들이 햄버거 먹고 싶은데 |
| CONTEXT | 못 먹으니까 |
| CONTEXT | 그래도 맛은 참 건강하다 |

이것은 **assistant가 선택한 진단 근거**이지 모델이 자동으로 찾은 선택이나 의미 승인된 TARGET이 아니다. 실제 `여기`가 어떤 장소/대상을 지칭하는지는 판단에서 별도로 검증해야 한다. 이 입력에서도 PASS/UNCERTAIN이 가능하다. 특정 문장을 찾으면 경고하는 코드나 사건 이름 규칙은 추가하지 않았다.

선택 상한 때문에 추가만 한 실험은 아니다. 1회차의 `이걸로` TARGET·유기농 햄버거·메뉴 특색/의미 인용은 교체되고, 2회차의 사연·부대찌개·“막 해서 먹는 거 아니야?”도 교체된다. 새 입력은 TARGET과 몇몇 CONTEXT를 함께 바꾸므로 개선돼도 **앞 반문 한 줄의 독립 효과**라고 주장할 수 없다. 건강한 맛의 원문은 두 조건 모두 반드시 유지한다. 기존 전체 원문과 교체 전 선택은 서버 측 packet에 남는다.

N5/N6의 양쪽 요청은 기존 선택·원문·판단 문구가 완전히 같다. 정상 라벨이나 문맥을 변형하지 않는다. 두 정상 대조만으로 전체 오탐 경계를 검증하지는 못하며, 다음 실제 결과도 각 조건 한 번이므로 안정성/일반화 성능으로 쓰지 않는다. C/D 회귀와 새로운 지역·음식의 정상 사례는 별도다.

### 결과별 다음 행동

- 진단 선택에서 B만 검토되고 정상은 PASS라면: 새 인용의 실제 대상/관계와 다른 쟁점 차용 여부를 사람이 먼저 검수한다. 이후 일반적인 자동 선택기 보강 여부를 검토한다.
- 두 선택 모두 B PASS라면: 확인된 문맥 범위 안의 의미 기준 문제는 남는다. 같은 시험을 성공할 때까지 반복하거나 정답을 프롬프트에 넣지 않는다.
- 정상 대조가 검토되면: 오탐 경계가 깨진 것이므로 미채택한다.
- 계약 거절·미확인 비용·불완전 응답이면: 탐지 결과와 분리해 기록한다.

## 보존과 한계

미리보기의 8요청 상한 추정 **$0.0508201**은 향후 예약 규모 참고이며 **이번에 예약하거나 소비한 금액이 아니다**. 추가 호출/예약 **0**, 기존 승인 잔여 **$0.4683626** 그대로다. 모델/단가는 이전 실험의 고정 설정을 보존했고 실제 청구액을 보장하지 않는다. 6개 새 검사 포함 Python **420개 통과**는 입력/계약 검사이지 탐지 성공률이 아니다.
